# Solara AI

Experimental model research by Solarna Systems, separate from the Solara desktop application.

The work studies sequence learning and memory through small, controlled experiments, alongside tools for reproducible evaluation and recovery of interrupted runs.

## Status

Research in progress. Models are trained from random initialization for the experiments; there is no released general-purpose language model or selected final architecture.

Results on synthetic tasks are not evidence of conversational ability or general reasoning.
